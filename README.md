# Wade for Linux

Wade is a private AI agent that runs entirely on your Linux machine, so nothing you type or any file it reads leaves your computer. Put all the Wade files in one folder, install Ollama with curl -fsSL https://ollama.com/install.sh | sh, and pull a model with ollama pull llama3.2:3b. Then run chmod +x wade_start.sh once and start Wade with ./wade_start.sh. The launcher installs the Python packages it needs, starts the server, and opens your browser already signed in, with no token to copy. Wade can list, read, write, and delete files, but only inside ~/wade_workspace, and every action needs your Allow click first. If the status light is red, check that Ollama is running and that the model name in wade_start.sh matches ollama list.
