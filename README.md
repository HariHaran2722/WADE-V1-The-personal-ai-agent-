# Wade for Linux
Wade is a personal AI agent that runs entirely on your own machine. Nothing you type, no file it reads, and no reply it generates ever leaves your computer. On Linux it is made up of five files that should all live together in one folder: wade_server.py is the backend that talks to your local model and enforces every security rule, wade_security.py holds the token, rate limiting and file-permission logic separately so it is easy to audit, wade_index.html is the interface you use in your browser, wade_start.sh is the launcher that brings everything up, and wade_start.desktop is an optional launcher that lets you start Wade with a double-click from your desktop or applications menu.
Before the first run you need Python 3 and a model backend. The simplest option is Ollama, which you can install with curl -fsSL https://ollama.com/install.sh | sh and then fetch a model with ollama pull llama3.2:3b. Once installed, Ollama runs its own server in the background, and that is all Wade needs. Wade works with any model Ollama can run, so if you prefer a different one you only have to change the model name in the launcher. If you would rather skip Ollama, Wade also supports llama.cpp directly: get a .gguf model file and a llama-server build, set WADE_BACKEND to llamacpp, and point WADE_MODEL_PATH at your model file.
